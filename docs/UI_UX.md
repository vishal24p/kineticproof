# Evidence-first web interface (desktop-first)

Four connected stages, not merely four marketing pages:
1. **Investigate:** choose supported experiment, hypothesis/procedure, materials, safety, length and camera instructions.
2. **Observe:** upload real clip, inspect object selection and video-frame overlay, see provider identity (OpenCV/open model/Meta) and quality/gap indicators.
3. **Evidence:** plot original time-indexed motion signal, cycle picks, measured period with uncertainty, reference and theory shown separately, bad-frame warnings, raw export and method provenance.
4. **Next trial:** evidence-grounded follow-up question or controlled variation. Label whether generated by deterministic template/open model/Meta Muse; never imply an AI-authored explanation is a measurement.

Essential states: loading/queued, unavailable provider, invalid file, no track, ambiguous object, partial occlusion, insufficient cycles, camera motion, absent calibration, spend budget exhausted, successful measurement with limitations. Users must be able to inspect a failed case without fabricated outputs.
