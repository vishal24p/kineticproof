# Privacy, cost, delivery and scientific risk controls

- **Media privacy:** avoid filming identifiable people when possible; secure consent for anyone included; publish only permissioned footage; purge uploads by explicit retention policy, not assumptions.
- **Local API retention and ownership:** uploaded media, traces and overlays live in the app-owned temporary directory until process shutdown. A process-random HMAC key signs an anonymous browser-session cookie established by `POST /api/session`; observation ownership is isolated by that cookie, but it is a bearer credential, not account authentication. A stolen cookie grants the same session's access. Restart invalidates cookies and loses process-local observations. Observation endpoints and session bootstrap use `Cache-Control: no-store`; `/health` remains public. Set `KINETICPROOF_COOKIE_SECURE=1` behind hosted TLS. Do not expose publicly until aggregate storage and concurrency limits and host-specific retention are defined and implemented. The UI bootstrap and same-origin proxy cookie forwarding remain a dependent follow-up, not verified by API tests.
- **API spend:** free credits applied != unlimited free calls. Obtain user approval for card, hard budget, max jobs/retries and cloud resources before paid activity. Spend alerts may not be hard caps.
- **Supply chain:** inspect any MCP/agent skill install scripts, packages, weights licenses and required permissions. Existing GStack/ECC don't have to be installed twice.
- **Measurement validity:** frame timing errors, occlusion, wrong target, camera movement, foreshortening, short/variable cycles; show warnings and independent references.
- **Provider availability:** open-first adapter ensures work progresses when Meta unavailable; Meta usage is still a final competition deliverable and time-sensitive risk.
- **Release:** unverified public repo secrets, media rights, hosted service sleep/timeouts, failing live demo, missing three-minute video link. Verify all before submission.

Open decisions requiring human judgment: spend limit, public video permissions, consent/retention duration, hosted provider choice. None blocks implementing private, offline-safe scaffolding.
